# زمین‌یار هوشمند

## اجرا
    cd zamin-yar
    npm start            # سرور محلی روی http://localhost:8765  (یا فقط index.html را در مرورگر باز کنید)
    npm test             # آزمون‌های عددی و ورودی مختصات (هسته)
    npm run test:e2e     # آزمون‌های مرورگر (نیاز به سرور روشن و Playwright)

## ساختار
- `core.js` هسته‌ی مستقل از DOM: هندسه و مساحت، سیستم مختصات، ورود مختصات، موتور ارزش‌گذاری، تاریخچه‌ی قیمت، اشخاص و موتور تقسیم
- `js/` رابط فارسی راست‌چین: نقشه، ورود مختصات، فرم ثبت، فهرست، تنظیمات، اشخاص/تقسیم، پروژه
- `vendor/` کتابخانه‌های محلی (Leaflet، proj4، SheetJS، JSZip) ⇒ ورود فایل مختصات کاملاً آفلاین است

## سرویس‌های اینترنتی (بدون کلید API)
- ماهواره: Esri World Imagery — نقشه‌ی خیابانی: OpenStreetMap — جست‌وجوی نام: Nominatim
- هر سه نیاز به اینترنت و رعایت شرایط استفاده دارند؛ برای استفاده‌ی تجاری/پرحجم سرویس مجاز یا پولی لازم است.
