# زمین‌یار هوشمند

ثبت زمین روی نقشه، اندازه‌گیری با GPS، ورود مختصات آماده، ارزش‌گذاری قابل تنظیم و تقسیم زمین‌ها بین اشخاص — با رابط فارسی راست‌چین، آفلاین و بدون نیاز به حساب کاربری.

## نسخه‌ی وب (روی کامپیوتر و گوشی)

همین کد، یک صفحه‌ی وب کامل است: ترسیم با ماوس (برای ثبت زمین روی کامپیوتر خیلی راحت‌تر است)، تشخیص خودکار مرز از تصویر ماهواره‌ای، ورود فایل مختصات، ارزش‌گذاری، برش زمین و تقسیم، ذخیره و پشتیبان‌گیری. نقشه‌ی پایه رایگان است (Esri World Imagery و OpenStreetMap) و کلید API نمی‌خواهد.

نشانی عمومی (GitHub Pages):

    https://hirad2969.github.io/Zamin_yar/

**فعال‌سازی یک‌بارِه‌ی Pages** (اگر هنوز فعال نشده است): در مخزن `Settings ← Pages`، در بخش *Build and deployment* گزینه‌ی *Source* را روی «Deploy from a branch» بگذارید، *Branch* را `main` و پوشه را `/ (root)` انتخاب کنید و Save بزنید؛ یکی دو دقیقه بعد همین نشانی باز می‌شود. فایل `.nojekyll` در مخزن هست تا Pages فایل‌ها را بدون پردازش Jekyll منتشر کند.

نکته‌های مهم نسخه‌ی وب:

- نشانی `https` است، پس مرورگر اجازه‌ی GPS را هم می‌دهد؛ با این حال GPS پیاده‌روی عملاً به گوشی می‌خورد.
- اطلاعات هر دستگاه فقط در همان مرورگر (localStorage) ذخیره می‌شود و بین کامپیوتر و گوشی خودکار منتقل نمی‌شود. برای انتقال یا پشتیبان‌گیری: تب «پروژه» ← «ذخیره‌ی فایل پروژه» و در دستگاه دیگر «بازکردن فایل پروژه».
- نشانی عمومی است (هرکس آن را بداند خودِ برنامه را می‌بیند)، ولی داده‌های شما روی دستگاه خودتان می‌ماند و به هیچ جایی فرستاده نمی‌شود.

## اجرا روی کامپیوتر خودتان

    npm ci               # نصب وابستگی‌ها (فقط برای آزمون‌ها و ساخت اندروید لازم است)
    npm start            # سرور محلی روی http://localhost:8765  (یا فقط index.html را در مرورگر باز کنید)
    npm test             # آزمون‌های عددی هسته (مساحت، ارزش‌گذاری، کسر دقیق، برش زمین)
    npm run test:dom     # آزمون رابط وب در DOM (بدون مرورگر): پنل برش، تب تقسیم، ذخیره‌ی خودکار
    npm run test:detect  # آزمون الگوریتم تشخیص مرز روی تصویر مصنوعی
    npm run test:all     # هر سه مورد بالا
    npm run test:e2e     # آزمون‌های مرورگر (نیاز به سرور روشن و Playwright)

## محاسبه‌ها داخل خود برنامه است

مساحت، ارزش هر زمین، جمع کل، سهم هر نفر، سهم دریافتی و اختلاف با حق هرکس — همه در `core.js` و بدون اینترنت یا هوش مصنوعی محاسبه می‌شود.

- **کسر دقیق:** سهم‌ها به‌صورت کسر صحیح (صورت/مخرج) نگهداری می‌شوند، نه اعشار گردشده؛ مثلاً سه سهم ۱/۳ دقیقاً ۱۰۰٪ می‌شود و هفت سهم ۱/۷ هم. در جدول تقسیم می‌توانید درصد بنویسید (`12.5`) یا کسر (`1/8`؛ هر دو دقیقاً یکی‌اند). گردکردن فقط هنگام نمایش انجام می‌شود.
- **کنترل جمع:** جمع سهم‌های هر زمین همیشه کنترل می‌شود (بیش از ۱۰۰٪، کمتر از ۱۰۰٪، سهم شخص حذف‌شده، تراز ارزش دریافتی + واگذارنشده با ارزش کل، تراز مجموع حق اشخاص با ارزش کل). نتیجه در تب «اشخاص و تقسیم» زیر عنوان «کنترل‌های محاسباتی» سبز/قرمز نشان داده می‌شود.
- **تشخیص خودکار مرز فقط یک پیشنهاد است** (نه محاسبه‌گر): همیشه قابل ویرایش است و عدد مساحت و ارزش از هندسه و تنظیمات خودتان می‌آید.

## زمین‌هایی که مرز مشخصی روی عکس ندارند

- **متراژ معلوم است** (مثلاً سهم عموها): در «تشخیص خودکار مرز» کادر «متراژ تخمینی» را پر کنید؛ مرز با همان مساحت ساخته می‌شود و با دکمه‌های ±۱۰٪ قابل تنظیم است.
- **متراژ معلوم نیست:** کادر را خالی بگذارید؛ برنامه خودش سطح هم‌رنگ را پیدا می‌کند، یا با GPS (دور زدن دور زمین) یا ترسیم دستی اندازه می‌گیرید.
- **مرز داخلی هیچ نشانه‌ای روی عکس ندارد** (دو قسمت هم‌رنگ و بدون خط): برنامه نمی‌تواند جای دقیق خط را حدس بزند. برای همین ابزار **«✂️ تقسیم یک زمین به دو قسمت با متراژ مشخص»** ساخته شده است: مرز کل زمین را دارید، متراژ یک قسمت را می‌دهید و خط جداکننده دقیقاً جایی کشیده می‌شود که مساحت درست شود (اختلاف در حد کسری از سانتی‌مترمربع). جهت خط را می‌توانید بچرخانید (گردشگر، دکمه‌های ±۱/±۱۵/±۴۵ درجه، یا «جهت پیشنهادی» که عمود بر کشیدگی زمین است)، دستگیره‌ی قرمز را با ماوس بکشید، متراژ را به مترمربع/هکتار/درصد (حتی کسر دقیق مثل ۱/۸) بدهید و در پایان دو قسمت را به‌عنوان دو زمین جدید ثبت کنید یا یکی را به فرم ثبت ببرید. خروجی GeoJSON هم دارد.

## ساختار

- `core.js` هسته‌ی مستقل از DOM: هندسه و مساحت روی بیضوی WGS84، کسر دقیق، سیستم مختصات، ورود مختصات، موتور ارزش‌گذاری، تاریخچه‌ی قیمت، اشخاص و موتور تقسیم، و برش زمین با خط مستقیم
- `detect.js` الگوریتم تشخیص مرز از تصویر (رشد ناحیه در فضای رنگ Lab) — مستقل از DOM
- `js/` رابط فارسی راست‌چین: نقشه، تشخیص خودکار، ابزار برش (`split.js`)، ورود مختصات، GPS، فرم ثبت، فهرست زمین‌ها، تنظیمات، اشخاص/تقسیم، پروژه
- `vendor/` کتابخانه‌های محلی (Leaflet، proj4، SheetJS، JSZip) ⇒ ورود فایل مختصات کاملاً آفلاین است
- `android/` پوسته‌ی Capacitor برای ساخت APK (`npm run android:sync`)
- `test.js` آزمون عددی هسته، `dom-test.js` آزمون رابط در jsdom، `detect-test.js` آزمون تشخیص مرز، `e2e*.js` آزمون مرورگری

## سرویس‌های اینترنتی (بدون کلید API)

- ماهواره: Esri World Imagery — نقشه‌ی خیابانی: OpenStreetMap — جست‌وجوی نام: Nominatim
- هر سه نیاز به اینترنت و رعایت شرایط استفاده دارند؛ برای استفاده‌ی تجاری/پرحجم سرویس مجاز یا پولی لازم است.
- اگر نقشه بارگذاری نشود، ترسیم مرز، ورود فایل مختصات، ارزش‌گذاری، برش و تقسیم بدون اینترنت کار می‌کنند (فقط تشخیص خودکار مرز به تصویر ماهواره‌ای نیاز دارد).
